# vibe_coder

> ⚠️ **Unmaintained / archived.** This was a personal experiment that is no longer
> being developed. It is published as-is in case any of it is useful. **You are welcome
> to fork it, adapt it, or take it over** — no support, no roadmap, no guarantees it
> runs cleanly today.

A tiny local multi-agent (planner / coder / reviewer) code generator with a Streamlit UI, running on local Ollama models.

## Status

Archived and unmaintained. Forks are encouraged — if you want to keep it alive, go for it.
